# Домашнее задание 3 (итоговый проект)

## Требования

В проекте задействованы только модули **стандартной библиотеки**:

- `re`
- `typing`
- `requests`
- `math`

## Установка зависимостей

Зависимостей нет - установка не требуется.

## Описание

Проект представляет собой Jupyter Notebook (`laureates_countries_task.ipynb`) для анализа данных о Нобелевских лауреатах. 

В ходе работы решаются следующие задачи:
1. Загрузка и парсинг вложенного JSON из API.
2. Обработка данных с помощью конфигурируемых процессоров (`json_dict_processing.py`, `laureates_configs.py`, `prizes_configs.py`).
3. Разведочный анализ данных (EDA).
4. Формирование выводов.

## Структура проекта

- `laureates_countries_task.ipynb` - основной ноутбук с кодом, графиками и выводами.
- `json_dict_processing.py` - ядро для обработки вложенных словарей по конфигу.
- `laureates_configs.py` - конфиги и процессоры для данных о людях и организациях.
- `prizes_configs.py` - конфиг и процессор для данных о премиях.
- `laureates_helpers.py` - вспомогательные функции.
- `dataset_helpers.py` - функции для работы с датасетами (фильтрация, группировка).
- `aggregations.py` - функции для вычисления агрегатов (среднее, медиана, топ-N).

## Запуск

Для работы ноутбука **не требуется** установка внешних библиотек
1. Все `.py`-файлы лежат в той же папке, что и `.ipynb`.
2. Открыть `laureates_countries_task.ipynb` в Jupyter Notebook или VS Code.
3. Выполнить `Kernel - Restart & Run All`.
   
## Проверка

Проект успешно проходит проверки:
- `flake8`
- `mypy`

Для проверки Jupyter Notebook (так как обычные линтеры не читают `.ipynb` напрямую) используется утилита `nbqa`.
Она прогоняет код ноутбука через стандартные линтеры.

```bash
# Проверка ноутбука
nbqa flake8 laureates_countries_task.ipynb --extend-ignore=E402
nbqa mypy laureates_countries_task.ipynb --ignore-missing-imports

# Проверка вспомогательных Python-файлов
python -m flake8 *.py
python -m mypy *.py
