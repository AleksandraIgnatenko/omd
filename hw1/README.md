# omd

Домашнее задание по курсу **python_basic**.

## Требования

Сторонние библиотеки не используются.
Задействованы только модули стандартной библиотеки:

- `collections`
- `typing`

## Установка зависимостей

Зависимостей нет — установка не требуется.

## Описание
Домашнее задание содержит пять задач на множества, словари и списки.

## Проверка

Проект успешно проходит проверки:

- `flake8`
- `mypy`

Запуск проверок:

```bash
python -m flake8 omd.py
python -m mypy omd.py
```
## Запуск программы
```bash
python omd.py
```
